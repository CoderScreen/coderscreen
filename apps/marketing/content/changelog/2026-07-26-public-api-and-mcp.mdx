date: '2026-07-26'
summary: 'Create API keys to manage interviews, assessments and candidates from your own tools or from an AI assistant.'
tags: ['New']
---

CoderScreen now has a public REST API. Create a key from the new **API** page in settings and you can list interviews, create assessments, invite candidates and pull results from your own scripts or ATS.

We also host an MCP server on top of the same API, so assistants like Claude or Cursor can do those things for you. The settings page gives you a config you can paste straight into your MCP client, with your new key already filled in.

- Keys belong to your organization and you can revoke them at any time.
- Responses use a stable public format that won't change when we change things internally.
