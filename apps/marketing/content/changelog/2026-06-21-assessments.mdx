Live interviews are great once you've got a shortlist. Assessments help you get there. Build a coding test, send it to candidates by email, and they take it on their own time while CoderScreen grades their code.

- Build assessments from a reusable question library, and give each question its own weight.
- Write test cases once and they're graded in 11 languages. Mark some as hidden so candidates can't code to the answer.
- Set an overall time limit and per-question limits.
- Candidates get a dedicated test-taking flow and a confirmation email when they finish.
- Review weighted scores for every submission, then archive the ones you're done with.
